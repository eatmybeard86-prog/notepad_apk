# Щоденник з голосовими (Android)

Особистий щоденник: текстові записи по днях, голосові нотатки, розділи за темами, календар, вхід відбитком пальця, копіювання в буфер.

## Можливості
- **Записи по днях.** В один день можна мати кілька записів у різних розділах. Текст зберігається автоматично.
- **Голосові нотатки.** Кнопка «Записати голос» у записі; відтворення, видалення. Файли `.m4a` (AAC) лежать у внутрішній пам'яті додатка.
- **Розділи.** «+ Розділ» на головному екрані створює тему. Натисніть розділ, щоб фільтрувати; довге натискання, щоб перейменувати або видалити (записи при цьому залишаються, просто без розділу).
- **Календар.** Вкладка «Календар» показує місяць, кольорові крапки позначають дні з записами. «Новий запис» створює запис на вибраний день. Натискання на назву місяця повертає до сьогодні.
- **Пошук** по тексту записів.
- **Обов'язки.** Окрема вкладка з підрозділами (Взвод управління, Взвод БпАК розвідки, Взвод НРК, Взвод важких БпЛА «Вампір», Група забезпечення). Підрозділи можна додавати, перейменовувати і видаляти. У кожному підрозділі є посади, за кожною посадою можна закріпити посадову інструкцію (PDF, DOC, DOCX) з файлів телефона. Файл копіюється в папку додатка, тож працює без інтернету і не зникне, якщо оригінал видалити. Інструкцію можна відкрити, замінити, надіслати або відкріпити.
- **Копіювання.** Кнопка копіювання в записі копіює його текст; у меню «⋮» → «Копіювати всі показані записи» копіює все з урахуванням розділу і пошуку.
- **Вхід відбитком.** Увімкнено за замовчуванням (якщо на телефоні налаштовано відбиток або PIN). Вимикається в меню «⋮». Коли блокування увімкнене, вміст прихований у списку останніх додатків, а скриншоти заборонені.

## Технології
Kotlin, Jetpack Compose (Material 3), Room, MediaRecorder / MediaPlayer, AndroidX Biometric. Мінімум Android 8.0 (API 26).

## Як зібрати
**Android Studio:** File → Open → вибрати цю папку → дочекатися синхронізації Gradle → Run на телефоні або емуляторі.

**Командний рядок** (потрібен Android SDK, `ANDROID_HOME` або `local.properties` з `sdk.dir=...`):
```
./gradlew assembleDebug
```
APK: `app/build/outputs/apk/debug/app-debug.apk`.

**GitHub:** після push у репозиторій workflow `Build APK` збирає APK; його можна завантажити на сторінці запуску в Actions (артефакт `voice-diary-debug-apk`).

## Структура
```
app/src/main/java/ua/diary/voice/
  MainActivity.kt          — навігація і блокування відбитком
  data/                    — Room: розділи, записи, голосові нотатки, підрозділи й посади
  audio/                   — запис і відтворення голосу
  ui/                      — екрани: головний (список/календар/обов'язки), запис, підрозділ, блокування
```
